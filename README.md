# Video Notes

Video Notes is a Moodle activity module that combines video playback with private, timestamped student notes.

## Features

- Upload, direct URL, YouTube and Vimeo sources.
- Progress based on video segments actually played.
- Resume from the last playback position.
- Timestamped notes with Important, Question, Review and Example categories.
- Click a note to return to the exact video position.
- Search, print, CSV export and text export of the student's own notes.
- Private-by-default notes with optional per-note sharing with teachers.
- Completion by minimum note count and/or minimum watched percentage.
- Teacher report containing only notes students explicitly shared.
- Backup/restore and Privacy API support.

Requires Moodle 4.4 or later.
